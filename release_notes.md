# MuPlayer V.6.0.0 🎵

MuPlayer 6.0.0 focuses on making the existing Liquid Glass interface and playback controls more reliable.

## Fixed and improved

- Reworked custom equalizer bands into touch-friendly horizontal sliders to avoid rotated-slider hitbox and clipping problems.
- Made the equalizer dialog scroll on smaller displays and kept the selected preset synchronized with playback-service state.
- Reserved space for the floating mini-player so it no longer covers the bottom of screen content.
- Kept the Settings tab selected when navigating to the listening statistics screen.
- Closed the default-sort dialog immediately after a selection.
- Added automated Android unit-test and debug-APK build checks, plus a tag-triggered release workflow.

## Included features

- Local music playback with background media controls.
- Search, sort, favorites, multi-select, and playlist management.
- M3U/M3U8 import and smart Liked Songs / Most Played playlists.
- Ten themes, optional Liquid Glass styling, equalizer presets, custom EQ, and bass boost where supported.
- Lyrics import, sleep timer, crossfade settings, and home-screen widgets.

## Requirements

- Android 8.0 (API 26) or newer.
- Debug APK builds are debug-signed; configure production signing before wider distribution.

Enjoy the music! 🎧
