# MuPlayer V.6.1.0 🎵

MuPlayer 6.1.0 adds playback-resume and library-management improvements while retaining existing UI and audio features.

## Added and improved

- Scan the on-device music library from Settings.
- Exclude folder names or paths from library scans.
- Resume the last track and position after reopening the app.
- Restore the previous playback queue when enabled.
- Sleep timer now uses the playback service's gradual volume fade before stopping.
- Clear temporary app/artwork cache without deleting music, playlists, or favorites.
- Updated About page with version and open-source credits.

## Existing playback features

- Background playback and lock-screen/media notification controls.
- Gapless playback where supported, configurable crossfade, equalizer presets, custom EQ and bass boost where supported.
- Lyrics, playlists, favorites, M3U/M3U8 import, listening statistics, ten themes and home-screen widgets.

## Requirements

- Android 8.0 (API 26) or newer.
